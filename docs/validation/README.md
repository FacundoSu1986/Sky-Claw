# Evidencia de validación

> **Audiencia:** operadores y responsables de aceptación.
>
> **Estado:** índice de evidencia fechada; no reemplaza el runbook.
>
> **Fuente canónica:** [validación en un rig real](../operations/real_rig_validation.md).

Cada paquete registra lo observado en un rig concreto. Un estado `Bloqueado` o
`No ejecutado` es evidencia de precondiciones incompletas, no una validación del
runner.
